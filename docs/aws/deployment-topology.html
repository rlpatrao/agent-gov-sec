AWS enforcement · two methods

Method 1Bedrock proxy — API Gateway chokepoint
API Gateway → proxy Lambda → Bedrock. The Lambda re-runs enforcement from the policy (input guards, tool-plan check, output redaction) and injects the model id server-side.
Method 2AgentCore — Cedar + interceptors
Per-persona runtimes → MCP Gateway. Cedar does authorization (one permit/forbid per agent × tool); request/response interceptor Lambdas do content control, in ENFORCE mode.
Data FGAC — separate chokepoint
Data reads bypass the LLM path. A separate data proxy runs under its own role and applies column masking and row filters before rows reach an agent.
